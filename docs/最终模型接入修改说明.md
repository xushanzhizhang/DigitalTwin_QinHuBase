## 一、本次目标与总体原则

用户已放弃 AI 自动建模路线，确定选用自己手工制作的模型。本次改造围绕五条明确要求：

1. **直接加载该模型，加载时不修改模型本身**；
2. **移除晴 / 阴 / 雨 / 高温 / 寒潮等天气情景**；
3. **初始视角站在琴湖基地东门**；
4. **点击功能分区标签可跳转对应区域**；
5. **保留传感器数据以体现智能化**，并将代码与说明同步到 GitHub。

总体原则：**模型文件保持原样，只在前端做"读取 + 索引 + 相机定位 + 数据叠加"，不写回任何模型数据。**

## 三、关于"运行时阴影"与"周边地面"的说明（不改动模型）

为避免误解，特别说明以下两项属于**渲染层 / 场景衬托**，不会写回模型文件，模型本身不变：

- **运行时阴影标志**：GLTFLoader 生成的网格默认不投影。为避免场景显"飘"、增强真实感，加载后仅在 three 对象上设置 `receiveShadow / castShadow` 标志（建筑、大门、桥等结构件投影；地形、水面、室内作物与全部植被不投影以控制开销）。这是运行时渲染属性，**不修改几何与材质，也不写回 GLB**。
- **周边收边地面**：模型地块本身有限，补一圈大地面 + 雾收边，避免看起来像浮空的模型底座。该地面是额外的场景衬托，不属于模型数据。

## 五、运行方法

```bash
# 1. 安装依赖（Python 3.11）
pip install -r requirements.txt

# 2. 从项目根目录启动后端（默认端口 8848）
python -m backend.app
# 或指定端口：
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8849

# 3. 浏览器打开
#    http://127.0.0.1:8848/  （或对应端口）
```

无需 npm、无需构建，前端依赖全部本地 vendor，模型经后端 `/assets/model/` 路由加载。
